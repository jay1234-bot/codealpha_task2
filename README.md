## 🎯 Overview

The **Premium Web Calculator** is a highly polished, responsive, and robust calculator built entirely from scratch using **HTML5, CSS3, and Vanilla JavaScript**. This project was developed as a task for the **CodeAlpha Internship**, demonstrating advanced frontend logic, layout design, and DOM manipulation without relying on any external frameworks.

## ✨ Features

- **📱 Fully Responsive**: Seamlessly adapts to Desktop, Tablet, and Mobile screens.
- **🎨 Glassmorphism UI**: Beautiful frosted-glass effects, subtle shadows, and premium layout.
- **⌨️ Keyboard Support**: Full keyboard integration (Numpad, Operators, `Enter`, `Backspace`, `Escape`) with visual tap animations.
- **🛡️ Custom Parser Logic**: Safe calculation evaluation avoiding raw `eval()`. Uses strict mathematical precedence (BODMAS).
- **⏱️ Real-Time Preview**: Instantly previews calculation results as you type.
- **📜 History Panel**: Keeps track of your previous calculations so you never lose context.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `calculator` folder.
3. Simply double-click the `index.html` file to launch the calculator in your default web browser.
4. *Alternatively*, start a local server: `python -m http.server 8080`.
